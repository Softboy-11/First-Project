# Yomade Enterprises Website

A responsive business website for **Yomade Enterprises**, showcasing its provision store and estate management services in Ibadan, Nigeria.

## 📌 Project Overview

The Yomade Enterprises website provides visitors with information about the business, its services, and how to get in touch. It features a clean layout, professional styling, and responsive navigation designed to provide a smooth browsing experience across desktop and mobile devices.

## ✨ Features

- **Responsive Design:** Adapts to different screen sizes, including mobile phones, tablets, and desktop computers.
- **Home Page:** Introduces the business and highlights its offerings.
- **Stores Section:** Presents information about the provision store business.
- **Properties and Estate Section:** Showcases the estate management and property-related aspect of the business.
- **Contact Section:** Provides visitors with a way to contact the business.
- **Mobile Navigation:** Includes a collapsible navigation menu for smaller screens.
- **Professional Branding:** Uses a gold and plum colour scheme to maintain a consistent visual identity.
- **Accessibility Considerations:** Includes semantic HTML structure, visible keyboard focus styles, and responsive layout features.

## 🛠️ Technologies Used

- **HTML5** — Structures the website content.
- **CSS3** — Handles styling, layout, colours, and responsive design.
- **JavaScript** — Supports interactive website functionality.

## 🎨 Design

The website uses a gold and plum colour palette to create a distinctive business identity. Its layout incorporates content sections, cards, navigation links, and prominent calls to action to make information easy to find.

## 🚀 Getting Started

### View the Website Locally

1. Download or clone this repository.
2. Locate the main HTML file.
3. Open `index.html` in your web browser.

If the main file has a different name, open that HTML file instead.

### Run with Visual Studio Code

1. Open the project folder in Visual Studio Code.
2. Open the main HTML file.
3. Launch it in your browser. You can also use the Live Server extension for local development.
